# 深度学习系统路线图

一个交互式的深度学习论文学习路线图，覆盖自监督学习、视觉 Transformer、扩散模型、3D 重建、大语言模型等方向。

主要学习资源来自：
- [科技猛兽（王嘉豪）](https://www.zhihu.com/people/wang-jia-hao-hku/columns) — 知乎专栏
- [Dezeming](https://www.zhihu.com/people/dezeming/columns) — 知乎专栏
- [李沐论文精读](https://github.com/mli/paper-reading) — B 站逐段精读

## 在线访问

[https://jhbutter.github.io/dl-roadmap](https://jhbutter.github.io/dl-roadmap)

## 功能

- 论文列表按模块分类，支持点击打勾追踪学习进度
- 按影响力分三级（核心 ★ / 重要 / 补充），字体和视觉层级区分
- 每条论文附 arXiv 链接、李沐精读视频、知乎专栏解读
- 支持自定义添加链接（标题 + URL + 图标）
- 支持云同步（通过 GitHub Gist 跨设备备份进度）
- 暗色主题，进度自动保存在浏览器本地

## 使用

直接打开网页即可。打勾状态自动保存在浏览器，自定义链接和云同步查看页面内操作指引。
